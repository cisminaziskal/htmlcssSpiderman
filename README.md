# Spiderman Temalı Web Sitesi

Bu proje, HTML, CSS ve JavaScript kullanılarak oluşturulmuş basit ve görsel olarak ilgi çekici bir **Spiderman temalı film sitesi** örneğidir.

## Özellikler

- Spiderman temalı kullanıcı arayüzü
- Duyarlı (responsive) tasarım
- HTML5, CSS3 ve basit JavaScript öğeleri
- Film hakkında görseller ve açıklamalar

## Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript (temel seviye)
